🔑 Google Drive API Scopes & Access Disclosure

Detailed explanation of how and why Application Backup by TechLIMS accesses Google Drive APIs.

Requested OAuth 2.0 Scopes:

  • https://www.googleapis.com/auth/drive.file (Recommended - View and manage Google Drive files that this app creates)
  • https://www.googleapis.com/auth/drive (Full drive backup management for dedicated shared drives and custom folder trees)

Why Does TechLIMS Backup Need This Access?

Application Backup by TechLIMS is an automated disaster recovery tool. Its primary function is to store encrypted, scheduled backups of application databases and server assets into your Google Drive account.

  • Dedicated Root Folder: All backup archives are stored exclusively inside a dedicated directory (default: LIMS_Enterprise_Backups/).
  • No Inspection of Personal Data: The application never reads, searches, accesses, or shares your personal Google Drive documents, Google Docs, photos, or files created by other applications.
  • Automated Retention Policy: The application uses Drive delete permissions strictly to prune outdated backup snapshots according to your configured retention schedule (e.g. 10-day sliding window).

Google API Services User Data Policy Compliance (Limited Use):

Application Backup by TechLIMS's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

📜 Privacy Policy

Effective Date: November 2026 | Application Backup by TechLIMS

1. Information We Collect

Application Backup by TechLIMS is a self-hosted or dedicated cloud backup utility. We do not operate third-party tracking, analytics, or behavioral cookies. The application stores only:

  • Configuration parameters: Server SSH hostnames, database user names, and backup cron schedules.
  • Cryptographic credentials: Passwords, SSH private keys, and OAuth tokens, all encrypted using AES-256-GCM.
  • Execution logs and audit manifests for compliance tracking.

2. Use of Google User Data

When you connect Google Drive to Application Backup by TechLIMS, the OAuth access token is used exclusively to transfer backup payload chunks (MySQL/PostgreSQL dumps and file deltas) and retrieve folder IDs inside your dedicated backup hierarchy. We do not sell, rent, commercialize, or share user data with any third parties or advertisers.

3. Data Security & Storage

All credentials stored in the local SQLite metadata database are protected with AES-256-GCM Authenticated Encryption with Associated Data (AEAD) derived via PBKDF2 (100,000 rounds). In-transit data between your server and Google Drive is encrypted using TLS 1.3 / HTTPS.

4. Data Retention & Deletion

Backup archives on Google Drive are automatically pruned when they age past your defined sliding-window retention policy (e.g. 10 days). You may revoke the application's access to your Google account at any time via Google Account Security Settings .
